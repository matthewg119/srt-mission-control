# Pest-Control Repeatable Format Bank (POV-first)

A cherry-pick bank of repeatable visual-hook formats for the pest-control avatar (Vargas,
first-person POV in Ray-Ban Meta glasses). Each format is a REPEATABLE skeleton: a fixed tool
+ a 2-4 shot sequence that can be re-shot/re-generated on any job with a different pest or
location. Field format: `Name | one-line visual hook (why the first second grips) | repeatable
skeleton (shot 1 -> shot 2 -> shot 3)`. No em dashes anywhere.

> This is the input to the creative director. The director suggests from this daily; the
> operator goes and finds a reference video for the chosen angle, which feeds the reference
> library (content_examples) and, when scrubbed, becomes a `workflows` row.

## Reusable research prompt (hand this to an assistant to grow the bank)

```
You are researching REPEATABLE short-form "visual hook" formats for a {INDUSTRY} brand whose
avatar films first-person POV. I need formats that can become an automatable workflow: a fixed
sequence of 2-5 shots that repeats on every job with only the scenario/location changing.

A format qualifies only if: (1) the first ~1 second delivers a visual reward or pattern
interrupt (something is about to happen and the viewer waits for the payoff), (2) it uses a
fixed, recognizable tool/action, and (3) it storyboards as a repeatable scene skeleton
(e.g. approach -> reveal -> resolve). Search Reddit (r/pestcontrol, r/oddlysatisfying,
r/natureismetal), TikTok/YouTube Shorts trends, and trade sources for real dramatic moments.

Return 30+ ideas grouped by category and subcategory. For each: `Name | one-line hook (why the
first second grips) | skeleton (shot 1 -> shot 2 -> shot 3)`. Use " | " as the field separator.
No em dashes. Then propose, for the top 5, what reference video angles the operator should go
film/find. Cite sources.
```

## 1. POV Roof / Exterior (roofline, gutters, eaves, soffits, perimeter)

- Roofline Walk Reveal | Glasses look down at your own boots edging a two-story roofline, first second sells real height and stakes | climb over the ridge -> walk the eave pointing out a soffit nest -> foam it, "one down"
- Gutter Scoop Horror | Gloved hand plunges into a packed gutter and lifts a fistful of crawling black sludge | peer into gutter -> scoop the muck to camera -> flush the run clean, "this is why they got in"
- Soffit Vent Nest Pop | Headlamp finds a wasp nest jammed behind a soffit vent, anticipation of the sting | spot the buzzing vent -> inject foam into the hole -> pull the dead nest out in one piece
- Dewebbing Speedrun | Webpole brush spins across a whole eave and every web vanishes in one pass | raise the brush to a web-choked corner -> sweep the full eave line -> pan the clean run, "web-free 90 days"
- Eave Crack Injection | Wand tip finds a hairline crack where ants stream out, "where do they live" curiosity | follow the ant trail up the wall -> find the entry crack -> inject and watch the line die
- Fascia Bat/Bird Check | Glasses tilt up under the fascia gap and eyes reflect back in the dark, jump-scare | walk the roofline scanning gaps -> light the gap and catch movement -> seal it with mesh
- Two-Story Ladder POV | First-person climb up a 32-foot ladder, phone-in-pocket vertigo grips instantly | foot on first rung -> climb looking down once -> reach the peak nest and treat it
- Chimney Cap Swarm | Lift the chimney cap and a cloud of wasps or a bird nest is revealed | approach the cap -> pry it up to reveal the nest -> vacuum or foam and re-cap
- Rain-Gutter Rat Highway | Camera follows greasy rub-marks proving a rodent runway on the roof | spot the grease trail -> trace it to the roof entry hole -> bait and seal the gap
- Whole-House Perimeter Spray Loop | POV walks the entire base of the house laying a treatment band, hypnotic continuous motion | start at the front door -> unbroken wand sweep down the wall base -> close the loop back at the door
- Weep-Hole Injection | The brick weep holes revealed as the secret pest doorway, "here is the door they use" | run the wall pointing at weep holes -> inject each one -> "closed every door"

## What makes these repeatable (design notes)
- Pattern interrupt in second one: darkness clicking to headlamp, a lid/cabinet/fridge coming off, boots on a rooftop edge, a mound erupting.
- Anticipation before payoff: "what is behind / under / inside this" (peel-back, pull-out, lift-reveal) then the resolve shot.
- Satisfaction loop: one continuous unbroken sweep (perimeter walk, dewebbing pass, granule fan) the eye wants to watch finish.
- Each skeleton is 2-4 shots with a fixed tool (webpole, foam injector, duster, spreader, scope, UV light), so the same skeleton reshoots on any job with a different pest.
